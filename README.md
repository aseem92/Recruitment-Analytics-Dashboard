# 📊 Recruitment Analytics Dashboard

An end-to-end Recruitment Analytics Dashboard developed using **Power BI** and **Microsoft Excel** to monitor recruitment KPIs, hiring pipeline, recruiter performance, salary insights, and candidate distribution.

---

## 🚀 Project Overview

This project demonstrates how recruitment data can be transformed into actionable business insights using interactive dashboards.

The solution consists of:

- Executive Recruitment Dashboard
- Recruitment Insights Dashboard
- Interactive Excel Dashboard
- Dynamic filtering using slicers
- DAX Measures
- Power Query transformations

---

## 🛠️ Tech Stack

- Power BI
- Microsoft Excel

- Power Query
- Data Modeling
- Pivot Tables
- Pivot Charts
