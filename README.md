# 📊 Recruitment Analytics Dashboard

An end-to-end Recruitment Analytics Dashboard built using **Power BI** and **Microsoft Excel** to analyze recruitment performance, hiring pipeline, recruiter efficiency, salary insights, and candidate distribution.

---

## Tech Stack

- Power BI
- Microsoft Excel
- DAX
- Power Query
- Pivot Tables
- Pivot Charts

---

## Features

- Executive Recruitment Dashboard
- Recruitment Insights Dashboard
- Interactive Excel Dashboard
- Dynamic KPI Cards
- Recruitment Funnel Analysis
- Recruiter Performance Analysis
- Department-wise Hiring
- Source Effectiveness
- Location-wise Hiring
- Experience Distribution
- Interactive Slicers
